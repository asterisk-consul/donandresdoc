# Paso a Paso: Creación de un Nuevo Artículo (Cubierta)

Este formulario es crucial para dar de alta el artículo en el sistema antes de poder ingresarlo al stock.

## 1. Datos Básicos e Identificación (Imagen 2: Agregar Artículo/Servicio)

| Nombre            | Que se ingresa                                                                         | Ejemplo                             |
| ----------------- | -------------------------------------------------------------------------------------- | ----------------------------------- |
| `Nombre`          | Ingresa la **Marca y el Código** de la cubierta                                        | Ejemplo: Pirelli P7 21008.          |
| `Descripción`     | Ingresa el **Modelo + Fecha + Tipo + Medida**                                          | _Ejemplo: TR88 - 47/21- LISA - 295_ |
| `Características` | Campo para información adicional no estructurada.                                      | (Opcional, si no es obligatorio).   |
| `Categoría`       | Selecciona la categoría **"ARTÍCULOS -> CUBIERTAS"** del menú desplegable.             |                                     |
| `Cod. interno`    | Ingresa el **código único** de la cubierta (código de fábrica o interno de tu negocio) |                                     |
| `Filtros`         | Selecciona el filtro **"1.8 Cubiertas"** del menú desplegable.                         |                                     |

## 2. Configuración de Ubicación y Precios

El resto de la configuración se encuentra debajo de la sección de datos básicos, desplegando los menús de programación y marcando casillas.

### 1. **Ubicación (1.-PROGRAMACIÓN DE LA UBICACIÓN):**

- Debes hacer clic en la casilla **□ Ubicación**.

- Al activarla, se abrirá la sección donde debes **seleccionar el depósito** al cual va a ingresar por defecto.

- **Selecciona el depósito "CUBIERTAS".**

### 2. **Precios (6.-PROGRAMACIÓN DEL PRECIO):**

- Desplázate hacia abajo hasta que veas la sección.

- Debes hacer clic en la casilla **□ Precios**.

- Esto te permitirá colocar el **valor de compra** del artículo que estás creando. ○ _(Nota: La imagen muestra varias opciones de programación. **Solo activa "Precios" **y **"Ubicación" **por ahora, siguiendo el flujo de ingreso)._

### **3. Finalizar la Creación**

- Una vez completados todos los campos obligatorios (⋆) y configurados la **Ubicación** y los **Precios**:

- Haz clic en el botón azul **GUARDAR** en la esquina superior derecha.

Al hacer esto, el nuevo artículo ("Cubierta") quedará registrado en el sistema y automáticamente seleccionado en la ventana "Agregar actividad" del remito de ingreso, permitiendo continuar con el flujo original.
