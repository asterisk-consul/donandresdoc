# 20.2.01- Orden de abastecimiento

## Creación de la Orden de Abastecimiento (OA)

Esta funcionalidad permite al personal de Taller/Mantenimiento cargar formalmente los materiales (repuestos) o servicios necesarios para realizar el mantenimiento de un vehículo.

### 1. Cabecera de la Solicitud

Esta sección vincula la necesidad de material o servicio a una Orden de Mantenimiento específica.

| Campo             | Propósito                                               | Instrucciones para Mantenimiento                                         |
| ----------------- | ------------------------------------------------------- | ------------------------------------------------------------------------ |
| Solicitud N° / ID | Número de identificación de la OA.                      | Se genera automáticamente.                                               |
| Fecha             | Fecha de creación de la solicitud.                      | Fecha de creación de la solicitud.                                       |
| Fecha Compromiso  | Fecha límite para la recepción del material o servicio. | Fundamental para la planificación del taller.                            |
| Descripción       | Resumen del motivo del abastecimiento.                  | Ej: Caja de Cambios.                                                     |
| Proveedor         | Entidad a la que se le hará el pedido.                  | Seleccionar el proveedor.                                                |
| Obs Actuar        | Justificación de la solicitud.                          | Detalle el motivo.                                                       |
| Km / Hs           | Lectura del vehículo al momento de la solicitud.        | CRÍTICO: Registrar el Km del camión para el que se solicita el repuesto. |

### Flujo de Continuidad (Proceso Integrado)

La **Orden de Abastecimiento (OA)** es el documento que inicia el ciclo de reposición.

1. **Activación de COMPRAS:** El personal de Compras hace clic en el botón **COMPRAS** para generar la Orden de Compra (OC) y enviársela al encargado de compras.

2. **Man Presupuesto:** por el momento sin uso \

**GUARDAR** solo registra los cambios para uso personal o borrador, manteniendo la orden en su estado actual.

**SIGUIENTE** formaliza la solicitud: **cambia el estado** de la orden (ej: a "En Revisión") y la envía automáticamente a la siguiente área de gestión (ej: Supervisión o Compras) para su procesamiento.

:::warning
⚠️ No presione SIGUIENTE hasta que la solicitud esté completa y lista para ser gestionada.
:::
