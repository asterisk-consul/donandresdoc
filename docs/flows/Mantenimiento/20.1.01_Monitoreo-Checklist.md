# Módulo: Mantenimiento y Uso

## Paso 1: Crear la Orden de Trabajo (OT) General

Utilizaremos el formulario **"Nuevo MAN Mantenimiento de unidades"**.

1. Acceder a la función **"Nuevo MAN Mantenimiento de unidades"**.

2. Completar los campos de la cabecera:

| Campos       | Descripcion                                                                                                    |
| ------------ | -------------------------------------------------------------------------------------------------------------- |
| `Fecha:`     | Fecha de inicio del trabajo.                                                                                   |
| `Unidad`     | **Seleccionar el vehículo** al que se le realizará el trabajo en Mayusculas y todo junto.                      |
| `Referencia` | Describir brevemente el motivo (Ej: Montaje inicial; ROTACIÓN; Reparación de pinchazo).                        |
| `Notas`      | Detallar las acciones solicitadas (Ej: Chequeo general de presiones).                                          |
| `Prioridad`  | Si son mantenimientos preventivos seleccionar **_Alta, Media, Baja_** y si no seleccionar **_mantenimiento_**. |

:::info
Si es necesario cargar una **Necesidad de compra** la misma se realiza en el se puede iniciar en el botón de **_ORDEN DE COMPRA_**.
:::

💾 Hacer clic en `GUARDAR` para acceder al detalle de las cubiertas.
